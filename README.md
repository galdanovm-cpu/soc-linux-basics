# soc-linux-basics

Мини‑практикум по базовым командам Linux для SOC Level 1.

## Цель
Научиться быстро выявлять подозрительные процессы и аномальные права на файлы — без сторонних утилит, только стандартными средствами.

## Что делал и какие команды использовал

### Поиск подозрительных процессов

- `ps aux` — список всех процессов с пользователями и потреблением CPU/MEM.
- `top` — интерактивный просмотр нагрузки и сортировка по CPU.
- `kill -SIGTERM <PID>` — корректное завершение процесса.

**Пример вывода (что искал):**
- Процесс с высоким CPU (например, >40% в top).
- Неизвестный пользователь (не root и не твой обычный юзер).
- Странная команда в колонке CMD (например, непонятный бинарник или скрипт из /tmp).

> В учебной среде я намеренно запустил тестовый нагрузочный процесс, нашёл его по PID через `top`, проверил командой `ps -p <PID> -o pid,user,cmd`, затем завершил через `kill`. В реальном инциденте это был бы кандидат на изоляцию.

### Проверка прав на файлы

- `ls -l /etc/passwd` — стандартные права на системный файл.
- `touch myfile.txt` + `chmod 600 myfile.txt` — создание файла с ограниченными правами.
- `ls -l myfile.txt` — проверка, что права действительно 600 (владелец читает/пишет, остальные — ничего).

**Почему это важно для SOC:**
Аномальные права (например, 777 на скрипты или исполняемые файлы в пользовательских папках) — частый маркер компрометации. Также проверяют, кто владелец файла и не менялся ли он недавно.

## Окружение

- ОС: Ubuntu (через WSL на Windows 11 Pro).
- Инструменты: `ps`, `top`, `kill`, `ls`, `chmod`.

## Вывод

Даже минимального набора команд достаточно, чтобы быстро собрать доказательства: кто запустил процесс, насколько он нагружает систему, какие у него права и откуда он стартовал. Это базовый триаж для L1 SOC.
